# TMDB CLI

A terminal tool that fetches movie info from The Movie Database API.

## Setup
1. `pip install -r requirements.txt`
2. Create `.env` with `TMDB_API_KEY=your_key`
3. Run: `python main.py "Inception"`

## Features
- Search any movie by title
- Shows rating, release date, and overview
- Displays top 5 matches
